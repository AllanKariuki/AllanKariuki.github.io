## Problem

Finding parking in a busy city wastes time and fuel. The Intelligent Parking Assistant set out to help drivers find available parking and get there.

## What I built

The Django backend, with endpoints for:

- user registration and profiles;
- directions;
- search;
- recording visits.

## Stack & architecture

Python and Django with PostgreSQL, developed under the Intelligent-Parking-Assistant GitHub organisation.

## Status / What's next

Completed as a team project.
